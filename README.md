Amazon Prime Video - Exploratory Data Analysis

Project Overview
This project focuses on Exploratory Data Analysis
of Amazon Prime Video content using Python.

Dataset
- titles.csv
- credits.csv

Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

Key Analysis
- Movies vs TV Shows distribution
- Content released over the years
- Top genres on Amazon Prime
- Country-wise content distribution
- IMDb and TMDB score analysis
- Movie and TV Show runtime analysis

Key Findings
- Movies account for 86.25% of content.
- Drama is the most common genre.
- 2021 had 856 titles.
- IMDb and TMDB scores have a correlation of 0.581.
